# Private-to-Public Boundary

This repository is a **clean-room portfolio extraction**, not a mirror of the private workspace.

## Intentionally excluded

- real rhythm-game beatmap files and archives;
- copyrighted songs, audio stems and derived media;
- player/replay identifiers, score histories and local database exports;
- OAuth/client credentials, cookies and browser profiles;
- model checkpoints and large generated artifacts;
- third-party analyzers, JavaScript bundles, WASM binaries and vendored runtimes;
- machine-specific absolute paths;
- private human-evaluation manifests and responses.

## Included

Only generic, original source code, synthetic examples, tests and documentation needed to explain the research architecture.

If a future public example uses a real dataset, its source, license, redistribution terms and anonymization policy should be documented before the data enters Git history.
